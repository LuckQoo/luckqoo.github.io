# 私人伺服器公開頁面

`/menu/private-servers.html` 是 EPOCH 的私人伺服器目錄，菇咕谷入口連至 `/private-servers/gugu/`。

此處只發布公開介紹及下載準備頁。GitHub Pages 版本不呼叫會員或交易 API，註冊、登入、儲值、購買與下載保持未開放；沒有後端、資料庫、SSH 金鑰或遊戲安裝檔。

來源是菇咕谷專案的 `website/`，使用該專案的 `deploy/export_epoch_preview.py` 明確挑選公開檔案並產生籌備頁。VPS 完成網站與遊戲驗收後，可將目錄卡片連至正式菇咕谷網址；須先確認 DNS、HTTPS、同源 API、登入及下載，不能僅解除這裡的停用按鈕。
